# Agent Logs

Use this directory only when a project needs durable references to agent runs.

Recommended convention:

- Store only logs that are needed for audit, validation, or handoff.
- Name logs with date, row ID, and purpose, such as `2026-05-08_SP-001_validation.md`.
- Link logs from `External_Artifacts.md` or Notes instead of pasting long transcripts into Dashboard tables.
- Delete or archive noisy logs when they no longer help future work.
