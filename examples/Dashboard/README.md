This Dashboard is an execution-state layer. It is not the canonical architecture or contract source.

Use it to track:

- Big Ideas: stable long-running directions
- Sessions: bounded time-slice work
- Decisions: choices that shape multiple sessions

Stable project truth should live in the project KB, docs, ADRs, specs, or contracts.

This is the minimal template. Use `examples/Dashboard-advanced/` only when a project needs stage plans, risk tracking, validation gates, automation, external artifact indexes, or agent log conventions.
